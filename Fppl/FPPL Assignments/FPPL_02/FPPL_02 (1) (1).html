def PSNR1 (I, I1):
    
    mse = np.mean((I - I1)**2)
    
    if mse == 0:
        return float('inf') #only possible if both the images are identical 
    max_pixel = 255.0
    psnr = 20 * log10(max_pixel / sqrt(mse)) 
    return psnr

Step 7 : Linear Scaling Parameters¶

The scaling factor $\alpha$ (gain) and the offset $\beta$ (bias) are calculated as:

$$ \alpha = \frac{255}{\max_{o} - \min_{o}} $$

$$ \beta = -\alpha \cdot \min_{o} $$

$ \text{This is for stretching a gray image so it uses the full range from pure black (0) to pure white (255), making it look clear and bright.} $

In [14]:
alpha=(255/(max_o-min_o))
beta=(-alpha)*min_o

Step 8 : Image Transformation¶

The final pixel values are mapped using the formula:

$$ n_{\text{img}} = (\alpha \cdot o_{\text{img}}) + \beta $$

In [15]:
n_img=(alpha*o_img)+beta
cv.imwrite("new_img.jpg",n_img)
new_img=cv.imread("new_img.jpg")
